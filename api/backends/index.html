    Backends API Reference¶

    Backend classes wrap a quantum framework behind one portable interface. Autodoc for the base class and factory is below; runnable examples follow.

    Base Backend¶

    superquantx.backends.BaseBackend ¶

    BaseBackend(device: str | None = None, shots: int = 1024, **kwargs)

    Abstract base class for quantum computing backends.

    This class defines the interface that all quantum backends must implement to provide quantum circuit execution, measurement, and algorithm-specific operations for SuperQuantX.

    compute_kernel_matrix ¶

    compute_kernel_matrix(X1: ndarray, X2: ndarray, feature_map: Any = None, shots: int | None = None) -> np.ndarray

    Fidelity quantum kernel K[i, j] = ||^2.

    Each data point is encoded with the feature map and simulated on this backend; the kernel is computed exactly from the resulting statevectors (shots is accepted for API compatibility and ignored). This is a real quantum-circuit kernel, but it is classically simulated, so it says nothing about quantum advantage.

    Creating Backends¶

    import superquantx as sqx

sim = sqx.get_backend("simulator", max_qubits=10, shots=1000)
pl = sqx.get_backend("pennylane", device="default.qubit")
qk = sqx.get_backend("qiskit")
print(type(sim).__name__, type(pl).__name__, type(qk).__name__)

    Portable Circuit Execution¶

    import superquantx as sqx

def bell_counts(name, shots=300):
    backend = sqx.get_backend(name)
    circuit = backend.create_circuit(2)
    backend.add_gate(circuit, "H", 0)
    backend.add_gate(circuit, "CNOT", [0, 1])
    backend.add_measurement(circuit)
    return backend.execute_circuit(circuit, shots=shots)["counts"]

for name in ["simulator", "pennylane", "qiskit", "cirq", "braket", "tket"]:
    print(name, bell_counts(name))

    Fallback Selection¶

    import superquantx as sqx

def first_working(names):
    for name in names:
        try:
            return sqx.get_backend(name)
        except Exception as e:
            print(f"{name} unavailable: {type(e).__name__}")
    raise RuntimeError("no backend available")

backend = first_working(["pennylane", "qiskit", "simulator"])
print(type(backend).__name__)
